## Concept

Each file does the same thing: reads [`data/phrase.txt`](data/phrase.txt) and outputs the contents.
In different languages. Just because it's possible.

```
data/phrase.txt → [any language] → stdout
```

## How to launch

```bash
git clone https://github.com/stompingcrit/polyglot-showcase
cd polyglot-showcase

# Example: Python
cd python && python main.py

# Example: Rust
cd rust && rustc main.rs && ./main

# Example: Go
cd go && go run main.go
```

The complete table of commands for each language is in [`LANGUAGES.md`](LANGUAGES.md).

## Add your language

Do you know a language that doesn't exist? PR welcome.

1. Create a `language_name/` folder
2. Add `main.{extension}` — reads `../data/phrase.txt`, outputs to stdout
3. Add to the table in `LANGUAGES.md`
